# Support

- **Setting up an inbox** — follow `docs/getting-started.md`, then run `agent-gmail doctor`. It names the problem and
  the fix for most setup errors. Still stuck? Open an issue with the **Inbox setup help** form and paste the
  `doctor --json` output (it contains no secrets; remove email addresses if you prefer).
- **Bugs** — open an issue with the **Bug report** form.
- **Ideas** — open an issue with the **Feature request** form.
- **Security problems** — never in a public issue. See [SECURITY.md](SECURITY.md).
