MCP connections

Called MCP servers in 0.34new

A connection is one place where an AI app uses Agent Comms: Claude Code in every folder, Claude Code in one project, Claude Desktop, and so on. You can have several for the same app. Each has its own name, its own parts and its own key.

An MCP server is a program an AI app starts to get more tools. Agent Comms is one server for all your accounts; a connection says which app starts it, where, and what it may reach.

Who can reach them

YesApps on this Mac, through your connections. That includes a Claude Code window on this Mac that you drive from your phone with Remote Control.
NoCloud sessions, such as Claude on the web or Claude Code in the cloud. They run on other computers, and Agent Comms runs only on this Mac.
