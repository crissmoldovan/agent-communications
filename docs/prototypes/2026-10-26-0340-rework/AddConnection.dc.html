What the key is fornew

It isn't a password. Apps on this Mac start Agent Comms as you, so a key doesn't keep anyone out. What it does: it tells Agent Comms which connection is calling, so Activity can say “used by {{nameShown}}”, and it lets you cut this connection off. Remove the connection, or replace its key, and the old key stops working.

If Agent Comms one day becomes reachable over the network, this key becomes a real secret.
