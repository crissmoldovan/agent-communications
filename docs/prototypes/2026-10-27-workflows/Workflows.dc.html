newEvery rule opens here as a straight-line workflow: When, Which messages, Ask a judge, Then do. It keeps its name, its version and its approval. Add a step or a branch, and its next version is a workflow, approved like any other.

A run is one message’s path through a workflow. Agents can draft a workflow through Agent Comms’ tools; only you approve one, in this app.
