Agent Comms: workflows, from a message to the right session

Drawn on 2026-10-27 for the owner’s feedback, before anything is built: a workflow as a graph of steps, with your example (a message comes in, the right project and session are found or started, in a worktree if you like, a Linear issue is made and closed when the session’s run ends), built by dragging steps, by describing it, or as text. Each screen is clickable. Add ?theme=dark to a screen’s address for its dark look.

A small new chip on a screen marks what the app can’t do yet. Everything else is there today.
