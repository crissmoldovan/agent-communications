How it’s made searchable

A small model turns each message into a list of numbers, called a vector, so Ask finds messages by what they mean: “invoice” also finds “bill” and “quote”.

The modelBuilt in, about 90 MB, downloaded once.Runs on this Mac
SummariesWritten by your local model server, if you set one up for a judge. Without one, the line is the message’s first words.Events → Judges ›
Where it’s keptA database in Agent Comms’ data folder, encrypted like the Queue’s items.
Sent anywhereNothing, for the vectors or for Ask.
Let sessions ask tooA session could ask about past messages through Agent Comms, as you do in Ask. What comes back is marked as from outside, like any message.
